# FixApp test build (Android)

**Download page: https://olivium-dev.github.io/fixapp-beta/**

This repository only hosts the public test version of FixApp for Android: a test build on a test server, with no real money. It holds no source code.

The download page and the APK live on the `gh-pages` branch. The FixApp release pipeline replaces them with each new test build; the page shows the version and the SHA-256 of the file.
